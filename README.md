# Shaharia Math

A modern, high-performance academic and mathematics coaching platform built for students across Bangladesh.

## Tech Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Radix UI, Framer Motion
- **Backend / BaaS**: Supabase (PostgreSQL, Auth, Edge Functions, Row Level Security)
- **Deployment**: Cloudflare Pages / Vercel

## Getting Started

### Prerequisites
- Node.js >= 18
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
